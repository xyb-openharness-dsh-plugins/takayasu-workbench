# PATIENT-FLOW · 患者旅程（假设版，0 访谈）

> 红线声明：本期 **0 患者访谈、0 条一手引语**。以下旅程是从病种知识、家属社群公开帖（二次来源，见 CLINICAL-DATA 台账）推演的**假设旅程**，不是访谈记录；每条旅程尾部的「假设依据」写明推演来源。真实访谈补位后须逐条修订并去掉"假设"字样。

## 旅程 A · 确诊建档（新患者，A 套档案对应）

1. 症状数月（乏力、低热、肢体无力/脉搏弱），辗转多家科室，最终风湿免疫科确诊「大动脉炎」。
2. 拿到血管超声/CTA/MRA 报告，术语看不懂：哪根血管、什么改变、严重吗——**患者不知道哪根血管受累、和上次比有没有变化**。
3. 开始激素治疗，药量逐周变化，患者记不清「从多少减到多少、什么时候减的」。
4. 工作台价值：把报告原文按血管节段记档（版本不覆盖），把激素变化按日期记档，确诊依据（医生诊断原话）留痕。
5. **假设依据**：罕见病确诊延迟的普遍现象（二次来源：罕见病指南目录与风湿病科普，未访谈）；「报告术语看不懂」为 R2 全线共性场景推演。

## 旅程 B · 长期随访（多年病程，B 套档案对应）

1. 每 1–3 个月复查：血沉/CRP、四肢血压；每半年到一年影像（超声/CTA/MRA）。
2. 激素减量过程中担心复发：**「血沉又高了，是不是又活动了」——只记医生原话与日期，工作台不判定**。
3. 药物从激素过渡到免疫抑制剂（具体药与剂量为医生决定），副作用与化验监测随药走。
4. 并发症筛查：血压、心功能（瓣膜反流）、动脉瘤、眼底——按医生嘱咐的节奏，工作台只记「医生说了查什么、结果原文」。
5. 工作台价值：指标趋势（方法/单位/机构可比组）、四肢血压成对差值（较上次）、复查节奏与「下次该查什么」清单。
6. **假设依据**：随访结构由「随访资料天然结构化」判定卡推演（ESR/CRP/血压/影像为周期性项目）；复发焦虑为慢性病共性推演。

## 旅程 C · 生育咨询（青年女性特有）

1. 病情稳定后考虑怀孕：**孕前要问医生什么？孕期血压怎么管？**——工作台只提供问题清单候选与医生回答原文记录。
2. 孕期随访频率与产科/风湿科双线并行，记录按日期双线挂。
3. **假设依据**：TAK 以青年女性为主的流行病学特征（二次来源，未核实中国数据）；生育问题清单为候选，逐条核对后入档。

## 旅程 D · 复诊准备

1. 诊室时间短，患者常忘记问：指标变化怎么看、药能不能减、下次什么时候查。
2. 工作台把最近指标、血压、用药变化、问题清单整理成一页，供就诊时对照。
3. 空状态必须有下一步按钮（去记录/去导入），不只写「暂无数据」。

## 孤儿页与暂缓项登记

- 场景→页面→数据→交互→验收双向映射见 INTERACTION-DESIGN §四；映射后孤儿页数必须为 0（探针出数）。
- 暂缓项：医保与救助资源整理（无可靠来源，M1 台账记「未取得」后裁剪或占位）；1.3 节禁用表达全站裁剪。
