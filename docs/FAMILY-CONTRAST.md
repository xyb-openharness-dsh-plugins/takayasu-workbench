## 四、元素体系借用清单（语义不借）

- 小粉宝：首页 hero 与疾病介绍入口（eyebrow + h1 + 说明 + actions）、病情整理五 Tab、分类区块眉题（metric-group-head）、最近值/差值/次数/来源卡、最近报告表、截图墙写法（README 用）。
- 小橙宝：一级/二级导航命名与分组（分组头 + 二级页签）、心智负担与生活影响的组织方式（life/mind 两页）、时间线事件泳道、空态与占位文案。
- 小莲宝（底本）：三段外壳 DOM、资料目录/AI 对话/设置/大字/?/版本顶栏顺序、demo-data 结构（profiles/metrics/events/docs/candidates）、src→build→lib 客户端链路。
- 不借：FIGO 分期、HPV/SCC-Ag、肿瘤标志物口径、粒缺、MRD、Day+N、血浆置换、危险度分层、疗效应答。
