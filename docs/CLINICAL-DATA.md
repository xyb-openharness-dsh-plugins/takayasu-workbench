## 二、失败与缺口

- 指南 PDF 原件：未取得（无下载通道凭据）→ 全部引「未取得原件，据二次来源」。
- NMPA 官方级核实（药品适应证）：未执行 → 用药页不写任何适应证断言，只记医嘱原文。
- 病友组织：未检索到可核实条目 → USER-RESEARCH C 层 0 条已核实。

## 三、指南使用边界

指南只定**内容边界**（哪些信息维度属于本病），不转成自测工具、不选治疗、不判活动度；所有阈值（ESR 正常范围、血压分级、狭窄程度）一律【待核】占位，临床审核前不启用。
