# DEV-REQUIREMENTS · 硬性要求清单

版本：0.1.0 ｜ 模式：无人值守夜间，所有「可回退默认值」晨审追认。

## 一、患者视角红线

1. 功能按患者关心的信息维度组织（血管受累、炎症指标、血压、用药、随访节律、生育、心理），不按医生任务（评分量表运算、鉴别诊断流程）组织。医生任务冒充患者需求属独立评审一票否决。
2. 每条功能线挂患者原话：**本期 0 访谈，0 条一手引语，如实声明**，改写句不冒充引语，USER-RESEARCH 按证据分层标注。
3. 0 患者访谈、0 临床审核在 README、SPEC、首页声明条三处显式标注。

## 二、数据层

1. ORDER BY rowid；显式 null（不用空串冒充）；in_use 标记；分节 *_title；分类不进趋势。
2. 无判读列：schema 禁止 diagnosis、risk_level、activity_score、severity、stenosis_grade 一类派生判定入库；派生值读时算、不落库。
3. 演示数据唯一源：页面不写死文案数字，图表/卡片/时间线读同一份 demo 数据；改一处三处同步变。
4. 受累血管节段、四肢血压、激素剂量、化验值全部为「医生报告原文 + 日期 + 来源」事实记录，不做程度判定。

## 三、前端

1. 令牌先于组件：brand/action/danger/warn/ok/soft + 圆角 16 + 间距 14；grep 十六进制只出现在 tokens.css。
2. 正文 15px、行高 1.65–1.68、tabular-nums、字号 12.5–15；按钮最小高 42–44px；:focus-visible 3px ring offset 2。
3. 三段外壳：原型声明条（全部模拟、未接入宿主）→ 侧栏 → 顶栏 + 页脚版本行。
4. 面板 25–45% 可拖可收、不遮业务主区；页脚贴底；[hidden] 控制显隐；断点 1180/900/600 三档。
5. 统一类名 .card/.pill/.notice/.empty/.table-wrap/.section-title；无判读列；无「不可恢复」文案。
6. 口径文案与数字同屏：「仅回顾，不解读」「解读归医生」「不同方法不合并」。
7. 私密三出口（导出/AI 上下文/摘要预览）共用同一过滤函数，页内写「N 条中私密 M 条」。
8. AI 输出永远是「候选/预览」，演示态明说未接入；agent-draft 协议按 34 号。

## 四、非肿瘤表达替换（照搬即失真的清单）

| 不许出现 | 换成 |
| --- | --- |
| 肿瘤分期/FIGO/线序/疗效应答/生存期 | 受累血管节段 + 活动期—稳定期 + 随访节律 |
| D+N 天数/疗程编号折叠 | 激素减量第 N 周 + 距上次活动评估 N 天 + 近 90 天就诊次数 |
| 肿瘤标志物趋势话术 | ESR/CRP「与疾病活动相关的化验」，标注方法/单位/机构可比组 |
| 指标卡下降级箭头 | 「较上次」或「近 30 天中位数」，不暗示好坏 |
| 分级徽章 CTCAE | 不做分级徽章；阈值一律【待核】 |
| 小时级轨道 | 用药 / 就诊 / 检查 / 影像 / 症状变化事件类型 |
| 急性加重自动判定提醒 | 只用患者与医生已确认的行动计划原话「若出现 X 联系 Y」，不写「你已进入活动期」 |

## 五、可回退默认值（无人值守，晨审追认）

1. **服务主体**：大动脉炎（TAK）确诊患者本人与授权代记者；青年女性（<40 岁）确诊后随访阶段优先；不覆盖未确诊人群鉴别诊断。
2. **病程覆盖**：确诊建档 → 活动/稳定随访 → 并发症监测 → 生育咨询；不覆盖急救与术前流程。
3. **MinerU**：未接入，按 18 号 v2 接口契约实现六部件（导入→队列→解析→候选→核对→归档）的桩件与失败路径，真实解析留接口。
4. **品牌占位名**：小弓宝 ArchPal（主动脉弓，占位待晨审追认，不冒充已授权品牌）。
5. **AI**：演示态本地候选生成，未接入真实模型；一键发送走 takayasu:agent-draft 协议草稿，不自动发送。
6. **临床研究线**：按 35 号四段链路做真实检索（四在线通道），TAK 试验少时如实展示候选数量，不做匹配指数与判读列。
