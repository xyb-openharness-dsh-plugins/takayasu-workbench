# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：大动脉炎（TAK）患者与授权代记者，以青年女性确诊后进入糖皮质激素/免疫抑制剂治疗与长期随访阶段者为主；覆盖确诊建档、活动期—稳定期随访与并发症监测；不覆盖未确诊人群的鉴别诊断

场景：把散落在血管超声/CTA/MRA 报告、风湿科化验单、四肢血压测量单和出院小结里的信息整理成活动期—稳定期随访线：受累血管节段只记医生报告原文并按日期留版本，ESR/CRP 按方法/单位/机构可比组展示，四肢血压成对录入只做「较上次差值」不做分级，激素减量按次记录，复诊前生成问题清单

核心流程：
1. 建立档案并导入或手工录入最近一次血管影像报告与化验结果
2. 核对候选信息，建立受累血管节段记录与确诊依据档案
3. 记录炎症指标、四肢血压与用药剂量变化
4. 整理并发症筛查节奏与影像复查计划
5. 生成复诊准备材料与问题清单

完成结果：得到来源可追溯、可核对的个人病程档案：受累血管节段版本记录、ESR/CRP 趋势（跨方法不合并）、四肢血压成对对比（只展示差值）、用药剂量变化线、并发症筛查节奏与复诊准备材料；所有候选信息经用户核对入档，不提供诊断与治疗建议

初始布局选择：business-first
